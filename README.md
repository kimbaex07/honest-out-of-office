One out-of-office auto-reply that tells the truth without getting anyone fired: the sender will not be checking email, because 400 unread messages have worn out their enthusiasm for the inbox — and it still thanks the reader and promises a reply on return. `main.py` writes the 180-character line to `entry.txt` and refuses to run if the line ever falls outside the 1–200 character limit.

## Run it

```sh
python3 main.py
```
